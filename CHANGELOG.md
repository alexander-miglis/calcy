# Changelog

All notable changes are listed here. Versions follow [Semantic Versioning](https://semver.org); pre-release builds
are `x.y.z-pre.N`.

## 0.1.0 (unreleased)

First version.

- Twelve modes: Simple, Advanced, Graphing, Programmer, Statistics, Matrix, Solver, Finance, Convert, Formulas,
  Notebook and Code, plus Settings and Help, in eight 8-bit colour schemes.
- Exact arithmetic engine with a computer algebra system, numerics, statistics, units and a formula collection
  (418 formulas, 56 constants), all written in C# without maths libraries.
- Sandboxed Python 3 interpreter with the `calc` module and turtle, ti_plotlib, ti_draw and casioplot.
- `calcy-cli`: terminal calculator and MCP server with 30 tools for AI assistants (31 with `--allow-code`).
- Packages for Windows, macOS and Linux (deb, rpm, tar.gz); bug reports from the app.
